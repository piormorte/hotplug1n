## `$ whoami`

Sou desenvolvedor **Fullstack em transição para Cybersecurity**, com foco atual em **Blue Team, SOC e segurança de aplicações**.

Meu objetivo é unir **engenharia de software + cibersegurança**, usando a perspectiva ofensiva para melhorar prevenção, detecção e resposta.

Não penso apenas em:

```text
"Como faço essa feature funcionar?"
```

Também penso em:

```text
"Como essa feature pode falhar ou ser explorada?"
"Quais dados ela expõe?"
"Como detectar um abuso?"
"Como posso reduzir o risco desde o desenvolvimento?"
```

Minha filosofia:

> **Build fast. Think secure. Defend by design.**
